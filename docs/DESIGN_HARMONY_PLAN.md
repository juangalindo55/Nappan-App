# Design System — Nappan Visual Language

## Design Direction

All pages use a single warm light theme. The landing page aesthetic applies everywhere — cart, checkout, profile, and any future screens.

---

## Color Palette

| Token | Value | Usage |
|---|---|---|
| Primary Background | `#FFF8EA` | page backgrounds |
| Secondary Background | `#F5EFDE` | section backgrounds |
| Card Background | `rgba(255, 252, 245, 0.86)` | card surfaces |
| Text Primary | `#2A1710` | headings, labels |
| Text Secondary | `#765E4B` | body text |
| Text Tertiary | `#9A7A61` | captions, hints |
| Border | `rgba(88, 55, 34, 0.13)` | card and input borders |
| Accent | `#D89B2B` | primary buttons, highlights |
| Success | `#4ADE80` | positive actions |
| Error | `#F87171` | remove, destructive |

---

## Typography

**Headings:** Cormorant (italic, serif), weight 500–700, color `#2A1710`

**Body text:** DM Sans, weight 400–600, color `#765E4B` or `#9A7A61`

**Labels / tags:** DM Sans, weight 800, size 10px, uppercase, letter-spacing 0.14em

---

## Component Patterns

**Cards:**
- Background: light cream
- Border: 1px subtle brown
- Shadow: `0 16px 42px rgba(62,35,19,0.08)`
- Radius: `1.6rem`
- Padding: 20px or 16px

**Buttons:**
- Primary (CTA): golden accent background + dark text
- Secondary: light background + dark text + border
- Danger (Remove): red background + light text

**Input fields:**
- Background: light cream / very light tan
- Border: subtle brown
- Focus border: golden accent
- Text: dark brown

---

## Visual Consistency Rules

Every page must have:

1. Same background color (`#FFF8EA`)
2. Same text color hierarchy (brown tones)
3. Same card style (light + subtle border)
4. Same button style (golden accent for primary)
5. Same typography (Cormorant headings + DM Sans body)
6. Same spacing units (20px, 16px, 8px)
7. Same rounded corners (16px on cards, 8px on buttons)
